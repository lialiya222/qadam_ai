# 🦾 QADAM AI — ЛФК Ассистент

**AI-ассистент для контроля техники выполнения реабилитационных упражнений через веб-камеру.**

## 1. Проблема и целевая аудитория
Жители сельских регионов Казахстана с нарушениями опорно-двигательного аппарата не имеют возможности ежедневно посещать врачей ЛФК в городских больницах. Наше решение приносит инструмент для реабилитации прямо в их смартфоны и ноутбуки.

## 2. Медицинское обоснование
Мы выбрали отведение плеча, так как это базовое движение для восстановления мобильности сустава после инсульта или травм ротаторной манжеты[span_0](start_span)[span_0](end_span). Наша цель не спортивный рекорд, а возвращение пациенту базовой бытовой амплитуды движений[span_1](start_span)[span_1](end_span). Поэтому мы фиксируем целевой угол подъема в безопасном терапевтическом диапазоне (70–90 градусов), чтобы избежать перегрузки сустава[span_2](start_span)[span_2](end_span).

## 3. Как работает AI-логика
Система должна отслеживать 3 точки на теле пациента, чтобы построить два вектора и вычислить угол между ними[span_3](start_span)[span_3](end_span):
* Точка A (Базовая ось тела): Бедренный сустав[span_4](start_span)[span_4](end_span)
* Точка B (Вершина угла): Плечевой сустав[span_5](start_span)[span_5](end_span)
* Точка C (Движущийся рычаг): Локтевой сустав[span_6](start_span)[span_6](end_span)

Для защиты от ложных срабатываний мы используем конечный автомат (State Machine) со строгими порогами[span_7](start_span)[span_7](end_span):
* **Состояние DOWN (Рука опущена):** Угол тетта < 30 градусов[span_8](start_span)[span_8](end_span). Цвет скелета на экране: нейтральный[span_9](start_span)[span_9](end_span).
* **Состояние UP (Рука поднята):** Угол тетта > 70 градусов[span_10](start_span)[span_10](end_span). Цвет скелета: зеленый (упражнение выполнено верно)[span_11](start_span)[span_11](end_span).

Повторение засчитывается ТОЛЬКО тогда, когда пациент перешел из состояния DOWN в состояние UP, а затем вернулся обратно в DOWN[span_12](start_span)[span_12](end_span).
